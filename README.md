# TaskieTown · 任务小镇

> 街机 HUD 风格的本地任务终端。把 GTD 的任务流和游戏的即时反馈放在一起——勾掉任务的瞬间有粒子、音效、经验值与连击提示。

**纯本地运行：无账号、无后端、无云同步、无遥测，数据只存在浏览器的 `localStorage` 里。**

---

## 功能一览

- **八个视图**：今日看板（三列拖拽）、收集箱、今天（含逾期回捞）、未来 7 天、项目（含进度与项目笔记）、稍后 / 灵感、已完成、回收站。视图走 URL hash，可直接分享链接。
- **完整任务模型**：标题、备注、三态（待办 / 进行中 / 已完成）、计划日期与截止日期分离、截止时间、优先级、项目、标签、预估耗时、子任务、重复规则、到期提醒。
- **任务流**：软删除可恢复、操作可撤销、任务可复制、重复任务自动生成下一实例、逾期标记。
- **成长系统**：完成得经验，经验升级，六个段位从「小镇新兵」到「星轨主宰」，连续完成触发 COMBO。
- **反馈层**：粒子爆裂、`+XP` 浮字、升级横幅、连击音效、屏幕震动，全部尊重系统「减少动态」偏好。
- **数据可迁移**：导出 / 导入 JSON，支持合并或覆盖，导入前逐字段 schema 校验。
- **显示选项**：浅色 / 深色 / 跟随系统，舒适 / 紧凑两档密度，侧栏可折叠。

## 快速开始

需要 **Node 20.19+ 或 22.12+**（Vite 7 要求）。

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5174> 。在地址后加 `?intro=1` 可强制重播开场动画。

**Windows 一键启动**：运行根目录的 `start-taskietown.ps1`，它会自动安装依赖、启动开发服务器、等端口就绪后用 Edge 应用模式打开（并解除浏览器自动播放限制，保证开场音效正常）。

```powershell
powershell -ExecutionPolicy Bypass -File start-taskietown.ps1
```

| 层次 | 选型 |

## 数据与存储

所有数据是单个 JSON 快照，结构为 `{ version: 1, tasks, projects, settings }`，写入 `localStorage`。启动时用同一套导入校验解析本地数据：解析失败会载入初始内容并提示改用导入恢复备份，不会静默丢弃旧数据。

导出文件名形如 `taskietown-2026-11-01.json`。导入限制：

- 文件大小上限 **5MB**
- **逐字段 schema 白名单校验**，任意一处不合格则整体拒绝，现有数据不变
- 任务 **ID 去重**校验
- 合并模式按 ID 跳过重复项，覆盖模式整体替换；两种方式都保留当前声音与外观设置

## 业务规则

这些规则集中在 `src/taskLogic.ts`，有单元测试覆盖：

- **重复任务**：完成时生成且只生成一个下一实例，用 `generatedFrom` 标记来源，防止重复生成；取消完成会连带移除它生成的下一实例。
- **月末重复**：`1–31` 号按月重复时夹到目标月最后一天，不会溢出到次月。
- **计划日期与截止日期独立**：重复推进时各自按规则计算，互不污染。
- **软删除**：只写 `deletedAt`，原状态保留，回收站可随时恢复。
- **输入边界**：标题 ≤ 200 字（必填），备注 ≤ 10000 字，预估耗时 0–1440 分钟，标签最多 12 个，开启提醒必须先设截止日期。
- **跨午夜**：每分钟重算本地日期，跨天后各视图数量与分组自动刷新。

## 快捷键

全局：

| 按键 | 作用 |
| --- | --- |
| `N` | 新建任务 |
| `Ctrl / ⌘ + K` | 聚焦全局搜索 |
| `?` | 打开快捷键说明 |
| `Esc` | 关闭当前弹层或清空搜索 |

任务卡片被聚焦（`Tab` 可达）后：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 打开详情抽屉 |
| `Space` | 完成或恢复任务 |
| `1` / `2` / `3` | 切换待办 / 进行中 / 已完成 |

输入框内编辑时不触发单键快捷键。看板卡片同时支持鼠标拖拽改状态。

## 设计风格

自建设计令牌，风格是「日间街机 HUD」：青绿 `#0a9e93` 为主色，洋红与金色做强调，深海军蓝侧栏，按钮使用硬投影（`0 4px 0`）营造实体按键感，叠加扫描线与浮游背景。圆角分 8 / 12 / 18 / 24 四级，动效强度可被系统「减少动态」整体降级。

---

## 已知边界

- 单用户单设备，跨设备需手动导出 / 导入。
- 浏览器通知依赖用户授权，且仅在页面打开时生效；未授权时任务仍正常保存并提示。
- 音效受浏览器自动播放策略限制，首次交互后才解锁。
- 移动端为降级适配：视图切换改为下拉选择，看板拖拽体验以桌面为准。
- 无多语言，界面为中文。
